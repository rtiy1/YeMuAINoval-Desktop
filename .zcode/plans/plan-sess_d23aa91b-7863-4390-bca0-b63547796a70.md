# 夜幕 AI 小说桌面版 — MVP 实施方案

## 目标
以 `packages/mcode` 为 Agent 大脑（子进程 NDJSON 通信），以 OpenFic 为设计灵感，构建一个沉浸式写作工作台。**Node + TypeScript 单语言全栈**，MVP 核心功能：项目管理 + 卷/章节编辑器 + 角色与世界观 + Agent 对话侧栏 + 本地持久化。

## 关键架构决策（已确认）
1. **MCode 只能子进程消费**：通过 `mcode -p --input-format stream-json --output-format stream-json --verbose` 启动，NDJSON stdin/stdout 通信。无进程内 SDK（所有 SDK stub 均 `throw 'not implemented'`）。后端写一个 `MCodeBridge` 进程管理器封装此契约。
2. **单语言全栈 Node/TS**：后端、桌面壳、前端共用 TS，`runtime.cjs`（Node）直接 spawn MCode，无跨语言桥接。
3. **Monorepo 结构**：pnpm workspaces，复用 OpenFic 的三段式布局（backend / frontend / desktop）。
4. **前端沉浸式写作工作台**：可折叠左导航 + 居中编辑器 + 右侧 Agent 对话，深色护眼。

## 核心实现：MCodeBridge（apps/backend/src/mcode/bridge.ts）
这是整个项目最关键的胶水层，封装 MCode 子进程的 NDJSON 协议：

- `spawnSession(opts)`: 用 `getMCodeCommand()`（来自 `packages/mcode/runtime.cjs`）spawn `bun run .../dev-entry.ts -p --input-format stream-json --output-format stream-json --verbose --session-id <uuid>`，stdio piped。
- 逐行 readline 解析 stdout NDJSON → 分类事件（`assistant_message`/`tool_use`/`tool_result`/`stream_event`/`result`）→ 经 WebSocket 转发前端。
- `sendUserMessage(text, attachments)`: 序列化为 NDJSON 写入 stdin。
- `interrupt()`: SIGINT 中断当前生成。
- 会话池：每个项目一个长驻 MCode 进程，消息追加到同会话以保持上下文。
- **系统提示注入**：首次发消息前，把该项目的角色档案、世界观条目、当前章节前文摘要拼成系统消息注入（让 Agent 拥有写作上下文）。

## 数据模型（Drizzle + SQLite，本地持久化）
对齐 OpenFic 精简版：
- `projects`（id, title, description, word_count, cover_path, created_at, updated_at）
- `volumes`（id, project_id, title, order）— 简化：OpenFic 必须有 volume，我们允许单卷默认
- `chapters`（id, project_id, volume_id, title, content, word_count, order, created_at, updated_at）
- `characters`（id, project_id, name, role, profile, appearance, personality, created_at, updated_at）
- `world_info`（id, project_id, title, category, content, order, created_at, updated_at）
- `agent_sessions`（id, project_id, mcode_session_id, title, created_at）— 映射前端会话到 MCode session UUID
- `settings`（key, value）— 存模型 provider/api_key/base_url

## 前端沉浸式工作台
- **技术**：React 19 + Vite + Radix Themes + TipTap（Markdown）+ Tailwind + zustand + TanStack Query + react-router。
- **布局**：左导航（项目/卷/章节/角色/世界观，可折叠到图标条）+ 中央沉浸编辑器（窄列居中、自动保存提示、字数统计、Find/Replace）+ 右侧 Agent 对话面板（流式 markdown 渲染、工具调用气泡、中断按钮、可 @提及章节/角色注入上下文）。
- **深色优先**：护眼配色，编辑器居中限宽。

## 技术选型一览
| 层 | 选型 | 理由 |
|---|---|---|
| 后端 | Fastify + better-sqlite3 + Drizzle ORM | Node 原生、轻量、本地持久化 |
| Agent | `packages/mcode` 子进程（NDJSON） | 复用已有 Agent 大脑，唯一可行集成方式 |
| 前端 | React 19 + Vite + Radix Themes + TipTap + Tailwind | 对齐 OpenFic 技术栈，沉浸式编辑 |
| 状态 | zustand + TanStack Query | 轻量，与 OpenFic 一致 |
| 实时 | ws (后端) ↔ 原生 WebSocket (前端) | MCode 事件实时转发 |
| 桌面 | Electron | 对齐 OpenFic，原生运行 |
